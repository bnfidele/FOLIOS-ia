## 🎯 Qu'est-ce que Folios IA ?

Une application web de chat intelligente et ultra-moderne construite avec :

- 🚀 **Alpine.js** - Réactivité instantanée sans compilation
- 🎨 **Tailwind CSS** - Design époustouflant et responsive
- ✨ **Lucide Icons** - Icônes vectorielles modernes
- 💾 **localStorage** - Persistance sans backend

### ✨ Cas d'Usage

```
💼 Professionnels       → Productivité accrue
👨‍🎓 Étudiants           → Aide à l'apprentissage
🎨 Créatifs             → Brainstorming collaboratif
🔍 Chercheurs           → Analyse rapide d'informations
```

## 🚀 Démarrage en 30 Secondes

```bash
git clone https://github.com/bnfidele/FOLIOS.git && cd FOLIOS
npm install && npm run dev &
npm run serve
# → http://localhost:8000
```

**Accédez instantanément à l'application. Aucune configuration requise !**

## 📊 Stack Technique Moderne

```yaml
Frontend:
  Réactivité: Alpine.js 3.x
  Styling: Tailwind CSS 3.4.0
  Icônes: Lucide Icons (SVG)
  Markup: HTML5 sémantique
  Logique: Vanilla JS (ES6+)

Stockage:
  Client: localStorage
  Optionnel: API REST Backend

Build:
  Task Runner: npm scripts
  CSS Compiler: Tailwind CLI
  Watch Mode: Mode développement
```
